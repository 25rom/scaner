# Price Radar

Определяет розничный диапазон по названию позиции: низ, верх, среднюю цену и маржу от закупки.
Каждая цена показана с источником, остатком и ссылкой.

## Быстрый старт без GitHub

Распакуйте архив и откройте `index.html` двойным щелчком. Страница работает сразу на стартовой базе лотов.

## Вариант А. GitHub Pages (страница по ссылке)

Страница на GitHub Pages открыта всем, у кого есть ссылка. Закупочные цены вводятся в браузере и никуда не сохраняются.
На бесплатном тарифе GitHub репозиторий для Pages должен быть публичным.

1. На github.com нажмите **+** → **New repository**. Имя: `price-radar`. Тип: **Public**. Нажмите **Create repository**.
2. На странице репозитория нажмите **uploading an existing file**. Перетащите туда всё содержимое распакованной папки и нажмите **Commit changes**.
3. Папка `.github` скрытая и может не загрузиться перетаскиванием. Проверьте: если в репозитории её нет, нажмите **Add file** → **Create new file**, в поле имени введите `.github/workflows/update.yml`, вставьте текст из файла `update.yml` архива и нажмите **Commit changes**.
4. **Settings** → **Pages** → в поле Branch выберите `main`, папку `/ (root)` → **Save**. Через 1–2 минуты там появится ссылка на страницу.
5. **Settings** → **Actions** → **General** → внизу **Workflow permissions** → выберите **Read and write permissions** → **Save**.
6. Вкладка **Actions** → **Обновление цен** → **Run workflow**. Дальше сбор идёт сам каждые 6 часов.

## Вариант Б. Приватный репозиторий

Данные и код видны только вам, страницы по ссылке нет.

1. Создайте репозиторий так же, но тип **Private**. Шаги 2, 3, 5 и 6 те же. Шаг 4 пропустите.
2. Чтобы посмотреть свежие данные: **Code** → **Download ZIP**, распакуйте, откройте `index.html`.

Страница, закрытая паролем, на GitHub доступна только на тарифе Enterprise. Для закрытого доступа по ссылке нужен свой домен или сервер.

## Как устроено

| Файл | Что делает |
|---|---|
| `index.html`, `app.js` | Страница и расчёт |
| `scrape.py` | Сборщик цен с площадок |
| `sources.json` | Список площадок и страниц, курс рубля |
| `data/lots.js`, `data/lots.json` | База лотов (обновляется сборщиком) |
| `data/manual.json` | Лоты, внесённые вручную |
| `.github/workflows/update.yml` | Автозапуск сборщика каждые 6 часов |

## Правила расчёта

- В расчёт идут только лоты с видимым остатком не ниже порога (по умолчанию 10 шт.).
- Лот без остатка, с невидимым или малым остатком показывается отдельно с причиной и в цену не входит.
- Среднее — обычное среднее цен учтённых лотов, не по количеству штук.
- Одинаковый лот на сайтах-зеркалах считается один раз.
- Данные старше 14 дней в расчёт не идут.

## Добавить площадку

В `sources.json` добавьте блок с именем и адресами страниц каталога. Поле `category` подсказывает платформу, если в названии лота её нет.

## Добавить лот вручную

В `data/manual.json`, в список `lots`:

```json
{"source": "accsmoll", "title": "TikTok Ads Германия PREPAY USD", "price": 2.36, "stock": 14,
 "url": "https://accsmoll.com/goods/tiktok", "category": "TikTok Ads", "fetched": "2026-11-12"}
```

## Запуск сборщика на своём компьютере

Нужен Python 3.10+.

```
pip install -r requirements.txt
python scrape.py
```

## Ограничения

- Сборщик не проверен на живых сайтах. Вкладка «Источники и состояние сбора» на странице покажет, какие площадки прочитались.
- Часть магазинов блокирует запросы с серверов GitHub. Для них сборщик нужно запускать со своего компьютера.
- Сайты, которые рисуют каталог скриптом, сборщик не читает.
- accsmoll запрещает автоматическое чтение, поэтому он отключён.
